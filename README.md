# TOPIK I ― 2級 合格トレーナー

TOPIK I（韓国語能力試験 初級）2級合格を目的とした、単一HTMLファイルの学習Webアプリ。
語彙 **1,669語** を収録し、すべてのハングルに **カタカナ読み** と **日本語訳** を付与します。
依存ライブラリ・ビルド・ネットワーク通信は不要です。

## 特長

- 語彙1,669語（1級/2級ラベル付き・15カテゴリ）を単語カードと語彙リストで学習
- **ハングル→カタカナ変換エンジンを内蔵**。CSV原本にカナ列がなくても実行時に自動生成
- 文法30パターン（例文のカナ読み・訳も自動付与）
- 演習4モード（語彙／訳→韓国語／文法／総合）。単語帳で選択中の級・カテゴリに出題範囲が連動
- 模擬試験15問・25分タイマー。提出後に全問のカナ読み・訳・解説を開示
- 学習状況を localStorage に保存（覚えた語数・累積正答率・模試最高点）
- スマホ最適化（下部タブ、セーフエリア対応、タップ領域44px以上）

## 変換エンジンが実装している音韻規則

1. 連音化（받침の次音節移動、ㅅは ㅅ のまま、二重パッチムは後半のみ移動）
2. ㅎ の脱落（좋아요 → 조아요）および激音化（좋다 → 조타、입학 → 이팍）
3. 濃音化（식당 → 식땅、읽다 → 익따）
4. 鼻音化（한국말 → 한궁말、입니다 → 임니다）
5. ㄹ 同化（신라 → 실라、남루 → 남누）
6. 口蓋音化（같이 → 가치、굳이 → 구지）
7. 二重パッチムの代表音化（닭 → 닥、여덟 → 여덜、값 → 갑）
8. 語中の平音 ㄱㄷㅂㅈ の有声化（부부 → プブ、기자 → キジャ）

規則で扱えない慣用読み（맛없다 → マドプタ、학교 → ハッキョ 等）は `OVER` 辞書で上書きしています。
カナは近似表記のため、カードは常にハングルを最大サイズで主表示にしています。

## 使い方

1. `index.html` をブラウザで開くだけで動作します。
2. GitHub Pages で公開する場合は Settings → Pages → Branch を `main` / `root` に設定。
   公開URLは `https://<ユーザー名>.github.io/<リポジトリ名>/` です。
3. スマホではそのURLを開き「ホーム画面に追加」するとアプリのように起動できます。

## リポジトリ構成

- `index.html` … アプリ本体（これ1つで動作）
- `TOPIK1_vocab.csv` … 語彙の原本（任意・参照用）
- `README.md` … 本ファイル
- `LICENSE` … MIT を推奨

## 語彙の追加・修正

`index.html` 内の `RAW` テンプレート文字列に、1行1語で追記します。
形式は `韓国語|日本語訳` （2級語は `韓国語|日本語訳|2`）、`#カテゴリ名` の行で分類が切り替わります。
カタカナは追記するだけで自動生成されるため、入力は不要です。
