# TOPIK I ― 2級 合格トレーナー

TOPIK I（韓国語能力試験 初級）2級合格を目的とした、**単一HTMLファイル**の学習Webアプリ。
ハングル入門から語彙1,669語・文法・模試までを1画面で完結させ、すべてのハングルに
**カタカナ読み**と**日本語訳**を付与します。依存ライブラリ・ビルド・通信は不要です。

## タブ構成

| タブ | 内容 |
|---|---|
| ホーム | 学習ステータス（覚えた語数・正答率・模試最高点）、推奨学習順、変換エンジンの検証例 |
| ハングル | 文字の仕組み、基本母音10／複合母音11／基本子音14／濃音5の字母カード、반절표（140マス）、パッチム7代表音、発音変化7規則、練習4モード |
| 単語帳 | 1,669語のフラッシュカード（級・カテゴリで絞り込み、覚えた語の除外）、検索付き語彙リスト |
| 文法 | 2級必修30パターン。例文はタップでカナ読み・訳を展開 |
| 演習 | 語彙／訳→韓国語／文法／総合の4モード。単語帳の絞り込みに連動 |
| 模試 | 読解15問・25分タイマー。提出後に全問のカナ読み・訳・解説を開示し200点換算で級判定 |

## カタカナ自動生成

内蔵の変換エンジンが、綴りではなく**発音**からカナを生成します。

1. 連音化（한국어 → 한구거）
2. ㅎ脱落（좋아요 → 조아요）
3. 激音化（입학 → 이팍、좋다 → 조타）
4. 濃音化（식당 → 식땅、읽다 → 익따）
5. 鼻音化（입니다 → 임니다）
6. ㄹ同化（신라면 → 실라면）
7. 口蓋音化（같이 → 가치）
8. 二重パッチムの代表音化（닭 → 닥、값 → 갑、여덟 → 여덜）
9. 語中の平音 ㄱㄷㅂㅈ の有声化（부부 → プブ）

規則で扱えない慣用読み（맛없다 → マドプタ、학교 → ハッキョ 等）は `OVER` 辞書で上書きしています。
カナは近似表記のため、カードは常にハングルを最大サイズで主表示にしています。

## 使い方

1. `index.html` をブラウザで開くだけで動作します。
2. GitHub Pages で公開する場合は Settings → Pages → Branch を `main` / `root` に設定。
   公開URLは `https://<ユーザー名>.github.io/<リポジトリ名>/` です。
3. スマホではそのURLを開き「ホーム画面に追加」するとアプリのように起動できます。

## 語彙の追加・修正

`index.html` 内の `RAW` テンプレート文字列に1行1語で追記します。
形式は `韓国語|日本語訳`（2級語は `韓国語|日本語訳|2`）、`#カテゴリ名` の行で分類が切り替わります。
カタカナは自動生成されるため入力不要です。

## データの保存

学習履歴はブラウザの localStorage に保存されます（キー: `tk_known` / `tk_stat`）。
ブラウザのデータを消去すると失われます。
